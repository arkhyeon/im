# 광부 소녀 27명 이미지 프롬프트

## 사용 방법

1. 아래 **공통 스타일** 문장을 각 캐릭터 프롬프트 뒤에 그대로 붙여서 생성하세요. 그래야 27명이 같은 그림체로 나와요.
2. **네거티브 프롬프트**를 지원하는 도구(Stable Diffusion, NovelAI 등)라면 같이 넣어 주세요.
3. 비율은 세로 **8:11** (예: 768×1056)로 뽑고, 배경은 투명(PNG)이나 단색으로 해 주세요. 단색이면 나중에 배경을 지울게요.
4. 파일 이름은 `캐릭터ID.png`(예: `apprentice.png`)로 저장해서 주시면 게임에 바로 넣을게요.
5. 한 명씩 마음에 들 때까지 여러 장 뽑아 고르는 걸 추천해요. 첫 캐릭터가 마음에 들면 그 이미지를 참고 이미지로 넣고 나머지를 뽑으면 그림체가 더 잘 맞아요.

```
cute anime girl mobile game character, full body, standing pose, holding a pickaxe, slightly chibi proportions (about 3.5 heads tall), big sparkling eyes, soft cel shading, clean thick outline, vibrant colors, friendly smile, modest cute outfit, centered, plain transparent background, no text, no watermark, high quality game asset
```
