# 광석 캐기 (React 방치형 게임)

광석을 탭해 골드를 캐고, 광부·드릴·공장·은행을 모아 자동으로 채굴하는 방치형 게임이에요.
Google 로그인, Firestore 저장, 실시간 TOP 3 랭킹을 지원해요.

## 게임 기능

- **광석**: 돌 → 구리 → 철 → 은 → 금 → 루비 → 사파이어 → 에메랄드 → 다이아몬드 → 운석. 탭·광부 피해만큼 골드를 주고, HP를 다 깎아 부수면 파괴 보너스 + 광석 아이템 + 가끔 장신구. 앞 광석을 10번 부수면 다음 광석이 열려요
- **장비 6종**: 곡괭이(탭 피해) · 헬멧(치명타 확률) · 장갑(치명타 피해) · 작업복(광부 효율) · 작업 바지(골드 러시) · 안전화(파괴 보너스·드롭률). Lv.0~100, 10레벨마다 나무→돌→구리→철→은→황금→루비→사파이어→다이아→전설로 재질이 바뀌고, 탭마다 전체 레벨 목록과 가격을 보여줘요
- **장비 세트**: 모든 장비가 Lv.10, 20, …이면 세트 단계마다 골드 +20%, 치명타 확률 +1%
- **광부 27명 (9등급 × 3)**: 일반·고급·희귀·영웅·전설·신화·초월·불멸·태초. 티켓 5종(동·은·금·다이아·태초)으로 뽑고, 금 이상 티켓은 50번 안에 전설 이상 보장
- **뽑기 연출**: 빛기둥 색이 가장 좋은 등급을 미리 알려주고, 전설 이상은 화면 번쩍 + 흔들림, 태초는 무지개
- **합성**: 같은 등급 3명 → 성공(+1등급) / 대성공 6%(+2등급) / 실패(1명만 돌려받음), 등급이 높을수록 성공 확률이 낮아져요
- **시너지**: 종족(인간·드워프·골렘·정령·용족)을 서로 다른 광부로 2/3/5명 모으면 효과, 정해진 조합 6개
- **장신구**: 반지·목걸이·부적·귀걸이·팔찌·깃털, 3칸 장착, 환생해도 유지
- **광석 시세 (시장)**: 20분마다 모든 유저의 매수·매도량으로 가격 갱신. 많이 팔린 광석은 떨어지고 안 팔린 광석은 올라요 (게스트는 이 기기 안의 모의 시세)
- **환생**: 골드·장비·티켓 가격만 초기화, 광부·장신구·광석 해금·시장 광석은 유지. 환생석 1개당 골드 +10%
- **골드 러시, 황금 박쥐, 출석·오늘의 미션, 오프라인 보상, 광고 무료 티켓** (광고는 지금 가짜)

## 로컬 실행

```bash
npm install
npm run dev
```

Firebase 설정이 없으면 게스트 모드(브라우저 저장)로만 동작해요.

## Firebase 연결 (Google 로그인 + 랭킹)

1. https://console.firebase.google.com 에서 **프로젝트 추가**
2. **Authentication > 시작하기 > Sign-in method > Google** 사용 설정
3. **Firestore Database > 데이터베이스 만들기** (프로덕션 모드, 위치는 `asia-northeast3` 서울)
4. **프로젝트 설정 > 내 앱 > 웹 앱 추가(</>)** 후 나오는 `firebaseConfig` 값을 복사
5. `.env.example`을 `.env.local`로 복사해서 값 채우기

```
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=프로젝트ID.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=프로젝트ID
VITE_FIREBASE_APP_ID=...
```

## 배포 (누구나 접속 가능한 주소 만들기)

```bash
npx firebase-tools login
npx firebase-tools use --add   # 위에서 만든 프로젝트 선택
npm run deploy                 # 빌드 + 호스팅 + Firestore 보안 규칙 배포
```

배포가 끝나면 `https://프로젝트ID.web.app` 주소로 누구나 접속할 수 있어요.

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `src/App.jsx` | 화면, 게임 루프, 저장, 랭킹 |
| `src/game.js` | 밸런스 값과 계산 함수 |
| `src/art.jsx` | SVG 그림 (광석, 일꾼, 곡괭이 등) |
| `src/firebase.js` | 로그인, Firestore 저장/불러오기, TOP 3 구독 |
| `src/styles.css` | 스타일과 애니메이션 |
| `firestore.rules` | 본인 기록만 쓰고 랭킹은 누구나 읽는 보안 규칙 |
